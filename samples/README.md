# samples/

Real statements go here when you want to run the test suite. **This folder is
gitignored** — statements carry your name, address and account number and must never be
committed to a public repo.

The tests expect:

    samples/Amex Jul 17 2026 Statement.pdf
    samples/Amex Aug 17 2026 Statement.pdf
    samples/CIBC Statement - Jul 13 2026.pdf
    samples/CIBC Statement - Aug 14 2026.pdf

Everyday use of the app needs nothing here — you just drop statements on the page.
